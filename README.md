# MapFan II Windows 11 互換パッチ

**MapFan IIのCD-ROMを所有している方向けの、非公式の互換パッチと代替インストーラです。**
MapFan本体・地図・住所データ・製品付属DLLは頒布物に含めません。利用者自身のCDからローカルで取り出し、対象のDLLだけを変更します。メーカー公式の更新プログラムではありません。

現在は **1.1.0-beta.5（試験公開向け）**。対応版を限定しています。

## 必要なもの

- Windows 11 x64の日本語環境。
- **MapFan II for Windows 95、1996年7月版のオリジナルCD-ROM** と、それを読めるドライブ。既存のMapFanインストールやWindows 95は不要です。
- [Python 3.11以降](https://www.python.org/downloads/windows/)（通常のWindows版。Install.cmdの操作画面にはtkinterを使用）。
- インストール先に約700MBの空き容量。

CDのファイルが対応版と一致するか、SHA-256で確認します。他の版のMapFanを動作保証するものではありません。

## CD-ROMからインストールする

1. このリポジトリの **Releases** から `mapfan2-win11-patch-1.1.0-beta.5.zip` を取得して、フォルダーに展開します。
2. MapFan IIのCDをドライブに入れます。
3. 展開した **Install.cmd** をダブルクリックします。管理者として実行しないでください。
4. フォルダー選択画面で、CDドライブのルート（`DATA.Z` がある場所）を選びます。
5. 続けて「インストール先の選択」で、保存先を入力するか「参照」で選びます。別ドライブや新しいフォルダー名も指定できます。
6. 「この場所にインストール」を押します。完了したら、選んだフォルダー内の `MapFanII-Win11.exe` を起動します。

**CDをISOに変換する必要はありません。7-Zipも不要です。** 導入後は地図データをインストール先から読むため、CDを取り出して使えます。

コマンドで実行する場合（D:は例です）:

```bat
py -3 install.py --media D:\
```

保存先を変更する場合:

```bat
py -3 install.py --media D:\ --target "C:\MapFanII"
```

既存ファイルがあるインストール先には本体を上書きしません。対応する導入済みMapFanを確認できた場合、Install.cmdでは「登録を修復して起動」の確認を表示します。それ以外は空の場所を指定してください。
旧アプリの文字コードに合わせ、日本語環境で表現できるパスが必要です。
1つのWindowsユーザーにつき1か所を使用してください。別の場所へ入れ直す場合は、先に現在のMapFanをアンインストールしてください。別の場所がアプリ一覧に登録されたままの場合、ファイルをコピーする前に案内して停止します。
選択画面でキャンセルしても導入先は作成・変更しません。コマンドで `--target` を指定した場合は、その保存先を使用し、選択画面は省略します。

### 既に導入済みの場合・登録だけを修復する場合

既定の導入先は `%LOCALAPPDATA%\MapFanII` です。以前に指定した別のフォルダーとは区別してください。
本体が存在し、アプリ一覧やOLE登録だけが失われている場合は、次のコマンドで修復できます。

```bat
py -3 install.py --target "%LOCALAPPDATA%\MapFanII" --repair
```

修復時は本体・地図を再コピーせず、保存データと現在の設定を残します。導入前のアンインストール用バックアップも取り直しません。
別の導入先が登録を使用している場合や、本体・アンインストーラーが変更されている場合は、上書きせず停止します。

### CDが対応版か確認するだけ

```bat
py -3 install.py --media D:\ --check
```

地図と書庫を読み取り、44ファイルの展開を検証します。アプリの導入先・INI・レジストリは変更しません。

### 所有するCDから作ったISOを使う場合

この場合だけ、別途[7-Zip](https://www.7-zip.org/)が必要です。

```bat
py -3 install.py --iso "C:\DiscImages\MAPFAN2.ISO"
```

一時展開先はWindowsの一時フォルダーです。製品データをGitリポジトリ内に展開しません。

## 互換性のために行う処理

- 16ビットの旧セットアップを使わず、CDの `DATA.Z` を読み取り、プログラムと必要なデータを展開します。
- `MFCO30.DLL` の参照先 `MFCUIA32.dll` をWindows標準の `OLEDLG.dll` に置き換えます。元DLLは `MFCO30.DLL.original` に保存します。
- 利用者別の `%LOCALAPPDATA%\VirtualStore\Windows` にMapFan用INIを設定し、導入前の内容は `uninstall-state.json` に保存します。
- MapFan専用OLEクラスを `HKCU\Software\Classes` の32ビットビューに登録します。登録前の値も `uninstall-state.json` に保存します。`.spf` / `.spg` の既定の関連付けは変更しません。
- 独自ランチャーが `SDBOLE32.exe -Embedding` を先に起動し、その後で `MapFan2.exe` を起動します。
- Windowsの「インストールされているアプリ」にユーザー単位で登録し、そこから専用アンインストーラーを起動できます。Program Filesへ配置する方式ではなく、既定の保存先はユーザーフォルダーです。

WindowsのシステムDLLを置換せず、サービス・ドライバー・自動起動項目は追加しません。インストーラ、ランチャー、アンインストーラーはデータをネット送信しません。製品本体に備わるインターネット機能については未検証です。

## アンインストール

MapFan関連アプリを終了して、**設定 → アプリ → インストールされているアプリ → MapFan II（Windows 11互換版） → アンインストール** を選びます。
専用画面で次のどちらかを選び、対象と処理内容を確認して実行します。

- **データを退避して残す（既定）**: 保存スポット・変更済みファイル・現在のINI等を退避してから本体を削除します。
- **完全削除（退避を作らない）**: 導入先の全ファイルと、この導入先に対応すると確認できた過去の退避・保管データを削除します。保存データは元に戻せません。

どちらも、この導入で追加したINI・OLE登録・アプリ一覧の登録を解除し、導入前からあった値は復元します。

退避先は `%LOCALAPPDATA%\MapFanII-UninstallBackups`。退避する方法では過去の退避データを削除しません。他の導入先が後から変更した設定や登録は保持します。
導入先の `Uninstall.cmd` からも起動できます。詳細は [アンインストール説明書](UNINSTALL.md) を参照してください。

アンインストーラーはパッチ本体に同梱し、単独の `mapfan2-win11-uninstaller-1.1.0-beta.5.zip` としても頒布します。
旧版へは `Register-Uninstaller.cmd` で追加できます。旧版でも方法を選択できます。退避する方法では本体フォルダー全体を保管します。復元記録のない外部設定は推測で削除しません。

### DLLパッチの復元

MapFanを終了してから実行します。

```bat
py -3 patch_mapfan.py --target "%LOCALAPPDATA%\MapFanII" --restore-dll
```

これはDLLだけを元に戻します。ユーザーデータ・INI・OLE登録のアンインストールは行いません。

## 確認状況

2026-10-25時点で、Windows 11 x64日本語環境の1台にて、元の互換パッチ・専用ランチャーで以下を確認しました。

- 地図表示と縮尺変更。
- 住所検索（東京都「渋谷」80件）。
- 通常終了後のランチャーによる再起動。

頒布用インストーラのCDディレクトリ読み取り・全ファイル配置・INI生成・DLLパッチと復元は、実CDと同じファイルを使った隔離テストで検証済みです。物理光学ドライブからの実機試験と、別PCでの導入は未実施です。
専用アンインストーラーは、データ退避・INIと登録の復元・他の導入先の変更保持・旧版のフォルダー保管、およびCD導入から削除までの隔離テストを実施しています。完全削除と同一導入先の退避データの削除も仮データで検証しています。
印刷・ルート計算・SpotFanの全編集機能・オンライン連携・WinHelp・16ビット付属ソフト・チュートリアルは未検証です。地図と住所は元CD当時の内容です。

不具合報告にはWindowsの版、CDの版、エラーメッセージを記載してください。**ISO・製品本体・地図ファイルをIssueに添付しないでください。**

## 開発・ビルド・頒布

ソースからは次の順に実行します。ソースZIPにはランチャーEXEが入っていないため、一般利用者はReleasesの配布ZIPを使用してください。

```bat
py -3 test_public.py
py -3 test_uninstall.py
py -3 build_release.py
```

`dist` に独自ランチャー入りZIPとSHA-256ファイルを生成します。Windows付属の.NET Framework C#コンパイラを使います。
`build_release.py` は許可したソース・文書・独自EXEだけを梱包し、公開用フォルダーおよびGit追跡対象に想定外のファイルがあれば停止します。
